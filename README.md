# 🌴 Mada Events & Voyages

Site de découverte de Madagascar : régions, prestataires touristiques, carte interactive.

## 📁 Structure

- `index.html` — Accueil
- `pages/` — Pages du site (régions, contact, carte, prestataires)
- `assets/` — CSS, JS, images
- `fiches/prestataires/` — Fiches générées automatiquement
- `scripts/` — Scripts utilitaires

## 🚀 Déploiement

Ouvrir `index.html` ou activer GitHub Pages.

## 🔄 Générer les fiches

```bash
bash scripts/generer_fiches.sh
